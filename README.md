# 📌 L'ARENA DEI GUARDIANI
Un gioco di ruolo (RPG) con interfaccia grafica e un sistema di combattimento a turni strategico, ispirato alle classiche battaglie della serie Pokémon.
Scegli il tuo eroe, affronta nemici del tuo stesso livello in duelli 1v1 e usa attacchi speciali o azioni difensive vincere!
## 🚀 Come eseguire il progetto
### Prerequisiti
- Java 25 (LTS)
- Gradle
### Istruzioni
```bash
git clone https://github.com/falcionirachele-svg/RPG.git
cd RPG
```
### Build del progetto
```bash
./gradlew build
```
### Esecuzione
```bash
./gradlew run
```
---
## 🤖 Uso di strumenti di AI

Durante lo sviluppo sono stati utilizzati **Google Gemini** e **GitHub Copilot** come strumenti di supporto: Gemini per la comprensione di concetti, il debugging e la generazione di frammenti di codice da prompt mirati; Copilot come assistente alla digitazione nell'IDE.

Ogni suggerimento è stato letto, compreso e adattato manualmente all'architettura del progetto, che è rimasto sotto il pieno controllo dello sviluppatore.
